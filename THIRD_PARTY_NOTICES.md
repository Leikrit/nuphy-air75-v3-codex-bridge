# Third-party references

This project is an independent Windows bridge. Its lifecycle-event design is
inspired by [NuNuBar](https://github.com/zesiwike-cpu/NuNuBar), and its Air75 V3
S4 protocol behavior is based on publicly documented, hardware-tested work in
[N Agent Bridge](https://github.com/bohu8264/N-Agent-Bridge). Those projects are
MIT licensed; see their repositories for the original notices and source.

The keyboard protocol is vendor-specific and is not an official NuPhy SDK. Use
the bridge only with the exact Air75 V3 USB interface described in `README.md`.
